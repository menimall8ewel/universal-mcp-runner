# Official Documentation Verification Skill

## Mandatory Rule
Before starting any task:
1. Identify all products, platforms, APIs, MCP servers, tools, and frameworks involved.
2. Load and review the latest official documentation for each involved tool.
3. Verify the intended configuration, capabilities, limitations, and recommended usage against official sources.
4. Do not rely on outdated memory or unofficial information when official documentation is available.

## During Work
- All architecture decisions, configurations, integrations, and code changes must be consistent with the latest official documentation.
- If documentation conflicts with previous design assumptions, follow the latest official documentation.
- Record important verification points before implementation.

## After Work
After completing any task:
1. Re-check the final result against official documentation.
2. Verify that configuration, APIs, permissions, and workflows match official recommendations.
3. Identify deviations and correct them before declaring completion.

## Scope
This applies to:
- Cloudflare products
- MCP servers
- APIs
- Agent frameworks
- External tools
- Any newly added integrations

The workflow is:
Official Documentation Check -> Plan -> Execute -> Official Documentation Re-check -> Complete
