### 自动加载原理
根据 OpenHands 官方文档的技术事实：

| 文件类型 | 触发条件 | 内容加载行为 |
|---------|----------|-------------|
| **Legacy .md** (传统格式) | 会话初始化时 | 自动全文加载到 LLM 上下文 |
| **SKILL.md** (AgentSkills) | invoke_skill() 调用时 | 渐进式披露 (仅名字/描述 → 调用时加载) |
| **AGENTS.md** | 会话初始化时 | 自动全文加载 (推荐简短内容) |

**本方案选择**: Legacy .md 文件在 `.agents/skills/` 目录
- ✅ 自动全文加载 (符合要求)
- ✅ 无需用户调用
- ✅ 无需关键词触发
- ✅ 初始化后即可使用完整规则
